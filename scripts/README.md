# Skript

Små verktøy jeg har skrevet under oppgaver og lab-øvelser. Alle trenger bare Python 3, ingen ekstra pakker.

| Skript | Hva det gjør | Brukt i |
| --- | --- | --- |
| [xor.py](xor.py) | XOR med gjentatt nøkkel på hex, tekst eller en fil | Cyberlandslaget 2025, outXORcing |
| [hexconv.py](hexconv.py) | Konvertering mellom hex, tekst, base64 og ASCII-koder | CryptoHack intro, CTFlearn |
| [is_sqlite.py](is_sqlite.py) | Finner SQLite-databaser ut fra headeren i et mappetre | Mobiletterforskning |
| [csv_to_kml.py](csv_to_kml.py) | Gjør eksporterte GPS-punkter om til et KML-kart for Google Earth | Innlevering i Advanced Device Forensics |

Kjør hvert skript med `-h` eller uten argumenter for å se hvordan det brukes.
